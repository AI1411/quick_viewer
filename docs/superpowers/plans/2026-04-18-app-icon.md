# QuickView App Icon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the placeholder app icon with the approved Fast-forward (cyan accent) design across all Tauri-bundled platforms.

**Architecture:** Hand-write a master SVG that matches the spec, rasterize it to a 1024×1024 PNG with the built-in macOS `qlmanage` tool (fallback: a tiny Node script using `@resvg/resvg-js`), then feed that PNG to `npx tauri icon` to regenerate the full platform icon set in `src-tauri/icons/`. No code changes to the app; only asset regeneration.

**Tech Stack:** Pure static SVG → PNG, then `@tauri-apps/cli@2.10.1` `icon` command. macOS-only toolchain (`qlmanage`). No new runtime or dev dependencies required for the primary path.

**Spec:** `docs/superpowers/specs/2026-04-18-app-icon-design.md`

### Task 2: Rasterize master SVG → 1024×1024 PNG

**Files:**
- Overwrite: `src-tauri/icons/icon.png`

Tauri's `icon` command requires a raster master. macOS ships `qlmanage`, which uses WebKit's SVG renderer, so gradients and solid fills come through cleanly.

- [ ] **Step 1: Rasterize via qlmanage**

Run:

```bash
qlmanage -t -s 1024 -o src-tauri/icons src-tauri/icons/icon.svg
```

Expected: creates `src-tauri/icons/icon.svg.png` (1024×1024). Note that `qlmanage` prints `Testing <path>` to stderr — that's normal.

- [ ] **Step 2: Rename to `icon.png` (overwrites old master)**

Run: `mv -f src-tauri/icons/icon.svg.png src-tauri/icons/icon.png`
Expected: no output; file exists at new name.

- [ ] **Step 3: Verify dimensions are 1024×1024**

Run: `sips -g pixelWidth -g pixelHeight src-tauri/icons/icon.png`
Expected output includes `pixelWidth: 1024` and `pixelHeight: 1024`.

- [ ] **Step 4 (fallback — only if Step 1 rendered incorrectly)**

If the output PNG looks wrong (missing gradient, wrong colors, blank image), use this Node fallback instead. Install `@resvg/resvg-js` as a one-off, render, then uninstall:

```bash
npm install --no-save @resvg/resvg-js
node -e "
  const fs = require('fs');
  const { Resvg } = require('@resvg/resvg-js');
  const svg = fs.readFileSync('src-tauri/icons/icon.svg');
  const png = new Resvg(svg, { fitTo: { mode: 'width', value: 1024 } }).render().asPng();
  fs.writeFileSync('src-tauri/icons/icon.png', png);
"
```

Expected: `src-tauri/icons/icon.png` regenerated, 1024×1024. Re-run the `sips` check from Step 3 to confirm.

- [ ] **Step 5: Visual spot-check**

Run: `qlmanage -p src-tauri/icons/icon.png 2>/dev/null`
Expected: Quick Look preview opens showing the two-triangle icon on a subtle gradient background. Close the preview.

### Task 3: Generate platform icon set with Tauri CLI

**Files:**
- Overwrite (via `tauri icon`): `src-tauri/icons/32x32.png`, `128x128.png`, `128x128@2x.png`, `icon.icns`, `icon.ico`, and any Windows-Store `Square*Logo.png` / `StoreLogo.png` the CLI regenerates.

- [ ] **Step 1: Regenerate all platform icons**

```bash
npx @tauri-apps/cli icon src-tauri/icons/icon.png --output src-tauri/icons
```

- [ ] **Step 2: Confirm the five bundle-referenced files were updated**

Run:

ls -l src-tauri/icons/32x32.png src-tauri/icons/128x128.png src-tauri/icons/128x128@2x.png src-tauri/icons/icon.icns src-tauri/icons/icon.ico

Expected: all five files present with a recent mtime (within the last minute).

- [ ] **Step 3: Quick-look verify the ICNS**

Run: `qlmanage -p src-tauri/icons/icon.icns 2>/dev/null`
Expected: preview shows the new icon. Close the preview.

- [ ] **Step 4: Verify a small size stays legible**

Run: `qlmanage -p src-tauri/icons/32x32.png 2>/dev/null`
