# QuickView アプリアイコン デザイン仕様

作成日: 2026-04-18

## 概要

macOS 向けファイルビューア QuickView のアプリアイコンを新規作成する。ミニマル・幾何学スタイルで「Quick（速さ）」を表現する Fast-forward（再生三角2枚重ね）モチーフを採用する。

## デザイン決定事項

| 項目 | 決定 |
|------|------|
| スタイル | ミニマル・幾何学 |
| モチーフ | Fast-forward（再生三角2枚重ね） |
| トーン | macOS 純正ユーティリティ寄り、白背景 |
| アクセントカラー | Cyan（#06B6D4） — データ／テック系の清涼感 |

## ビジュアル仕様

### キャンバスと形状

- キャンバス: 1024 × 1024 px
- macOS の squircle マスクは OS 側が適用するため、マスターアートワークは正方形フル出力でよい
- Tauri の multi-platform 配布のため、背景まで含めた不透明のマスターを 1 枚用意する

### カラー

| 用途 | HEX | 備考 |
|------|-----|------|
| 背景（上） | `#FFFFFF` | グラデーション開始 |
| 背景（下） | `#F1F5F9` | Slate 100、グラデーション終了 |
| 背景方向 | 135°（左上 → 右下） | |
| プライマリ三角 | `#0F172A` | Slate 900 |
| アクセント三角 | `#06B6D4` | Cyan 500 |

### シンボル座標（viewBox 100×100 基準）

- 左三角（プライマリ）: `M 20 22 L 56 50 L 20 78 Z` — fill `#0F172A`
- 右三角（アクセント）: `M 52 22 L 88 50 L 52 78 Z` — fill `#06B6D4`
- シンボルはキャンバス中央に配置、占有率は約 62%
- 角は鋭角（丸めなし）

### マスター SVG

```svg
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 100 100" width="1024" height="1024">
  <defs>
    <linearGradient id="bg" x1="0" y1="0" x2="100" y2="100" gradientUnits="userSpaceOnUse">
      <stop offset="0%" stop-color="#FFFFFF"/>
      <stop offset="100%" stop-color="#F1F5F9"/>
    </linearGradient>
  </defs>
  <rect width="100" height="100" fill="url(#bg)"/>
  <path d="M20 22 L56 50 L20 78 Z" fill="#0F172A"/>
  <path d="M52 22 L88 50 L52 78 Z" fill="#06B6D4"/>

```

## 書き出し要件

Tauri が要求する既存アセットを上書きする。

| ファイル | サイズ | 用途 |
|----------|--------|------|
| `src-tauri/icons/icon.png` | 1024 × 1024 | マスター PNG |
| `src-tauri/icons/icon.icns` | 16 / 32 / 64 / 128 / 256 / 512 / 1024（@1x, @2x） | macOS |
| `src-tauri/icons/icon.ico` | 16 / 32 / 48 / 64 / 128 / 256 統合 | Windows |

推奨生成手順: マスター SVG を 1024 PNG にラスタライズし、`npx @tauri-apps/cli icon <path-to-1024.png>` で残りのプラットフォーム別サイズを一括生成する。

## 可読性要件

- 16 px 表示（Finder 列、タブ）で「三角2枚」の構造が判別できること
- Dock 表示サイズ（128 px 程度）で主色とアクセントのコントラストが保たれること
- ダークモードでも極端に沈まないこと（白背景のため基本 OK、OS 側のスクリム任せ）

## 関連変更

- `.gitignore` に `.superpowers/` を追加（ブレインストーミングの一時ファイル保持用ディレクトリ）

## 非対象

- ランチャーアイコン以外のブランド展開（Web / リリースノート用バリアント等）は含まない
- アニメーション版は作らない
- マーケティング素材（スクリーンショット合成など）は作らない
